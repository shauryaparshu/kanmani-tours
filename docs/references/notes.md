# Reference notes (index)

Last updated: 2026-10-24. Read this file first, then the per-site profiles.

## Our direction in one line
Warm and editorial like Adams & Butler, with the confident scale and navigation structure of Y.CO. Real tour photography only. No paid fonts.

## Sites

### Site A: Adams & Butler
URL: https://www.adamsandbutler.com/
Profile: `adams-and-butler.md`
Like: serif display plus light sans pairing, warm off-white background (#FAF9F6), muted burgundy accent (#613842), fade-in reveals, offset overlapping images, tall image-card slider with the title on the image, nav goes from transparent to solid on scroll.
Dislike: long dense paragraphs, wordy copy.
Use for: typography feel, color restraint, image layout, card slider.

### Site B: Y.CO
URL: https://y.co/
Profile: `y-co.md`
Like: oversized uppercase hero type, one accent color used sparingly (#FFC719), nav shrinks to a mark on scroll, mega-menu with a featured item, large heading with an image that slides in.
Dislike: the loud yellow is too aggressive for our brand.
Use for: nav behavior, hierarchy and scale, mega-menu structure.

## What the two have in common
- A full-screen hero with a dark overlay and one clear message.
- Big, confident typography with a clear size hierarchy.
- Very restrained color: one accent, everything else neutral.
- Large imagery doing most of the storytelling.
- A navigation that changes state on scroll.

## Where they differ (choose deliberately)
- A&B is quiet, serif, warm. Y.CO is loud, condensed, high-energy.
- Kanmani Tours should lean toward A&B's mood, borrowing Y.CO's scale and nav structure.

## Fonts to evaluate (free licenses, verify before locking)
- Display serif: Fraunces, Cormorant Garamond, Newsreader
- Sans: DM Sans, Manrope
- Japanese: Noto Serif JP, Noto Sans JP
Reference sites use paid fonts (Nocturne, Gt, GT America). Do not use them.
