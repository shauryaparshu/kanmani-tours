# References folder

Purpose: visual and structural inspiration for the Kanmani Tours redesign. Claude reads this folder before any UI work.

## Rules
- Inspiration only. Never copy another site's photos, text, logos, exact layouts, or paid fonts. Mix ideas from several references into one original look.
- 3-5 sites, about 20 images maximum in total. More images cost more usage and add noise, not quality.
- Every site gets one markdown file (copy `_template.md`) and one line in `notes.md`.

## Files in this folder
- `notes.md`: index and summary of what we like across all references. Read this first.
- `adams-and-butler.md`, `y-co.md`: one profile per reference site.
- `_template.md`: copy this for each new site.
- Screenshots: `sitename-what.png` (see naming below).

## What to capture for each site
1. Hero at desktop width (the first screen).
2. One full-page scroll screenshot (section order and rhythm).
3. Typography close-up: a headline plus a paragraph.
4. A section where the color palette shows clearly.
5. The sections our site needs: tour or package cards, itinerary, testimonials, FAQ, enquiry form, footer.
6. Navigation open and closed, desktop and mobile.
7. Mobile view: hero plus one content section at phone width (about 390px).
8. Motion: write one line in the site's markdown file (screenshots cannot show it).
9. One or two anti-references: sites or sections you dislike, with the reason.

## Naming
`sitename-hero.png`, `sitename-fullpage.png`, `sitename-typography.png`, `sitename-colors.png`, `sitename-cards.png`, `sitename-nav-desktop.png`, `sitename-mobile-hero.png`, `anti-sitename-reason.png`

## Where to look
Awwwards, Dribbble, Pinterest. Search: "travel website design", "tour operator website", "luxury travel", "editorial travel website", "boutique travel agency", "Japan travel website". Also look at 2-3 sites outside travel (hospitality, restaurants) whose feel you love.

## Fonts
Use free-license fonts only (for example Google Fonts). Note any font you like on a reference, then find a free equivalent. Check licenses before using anything.
